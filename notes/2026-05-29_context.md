## What This Project Is

A 2×2 factorial study of DQN vs Double DQN agents on Pong and Breakout (Atari), studying the internal representations learned by the 512-dim penultimate layer of the CNN.

**Research question:** Do agents trained on structurally similar games develop similar internal representations, and does algorithm choice (DQN vs DDQN) affect representation quality?

**Original findings (already written up in latex/main.tex):**
1. Game effect dominates — t-SNE clusters separate by game, not algorithm
2. DDQN produces tighter, more structured representations
3. Cross-game cosine similarity is non-trivial (shared ball/paddle structure)
4. DQN has more dead neurons
5. DQN overestimates Q-values by 10-40%
6. Performance and representation quality are decoupled

## Network Architecture
```
Input: (4, 84, 84)
Conv(32, 8x8, s4) → ReLU
Conv(64, 4x4, s2) → ReLU
Conv(64, 3x3, s1) → ReLU
Flatten → Linear(512) → ReLU   ← REPRESENTATION LAYER (forward hook here)
Linear(n_actions)
```

Three sizes via net_scale: small ([16,32,32], 256-dim), medium ([32,64,64], 512-dim), large ([64,128,128], 1024-dim)

## Key Hyperparameters
- lr: 1e-4 (Adam), buffer: 100k, batch: 32, gamma: 0.99
- Target update: every 1000 steps, epsilon: 1.0→0.01 over 100k steps
- Grad clip: 10.0, checkpoint every 500k steps, seed: 42
